# Using Prompts

Prompts are reusable instructions you can apply to your conversations. Instead of repeating yourself every time, you save your instructions once and activate them whenever you need them.

## Two types of prompts

**System prompts** set the AI's personality and behavior. When you activate a system prompt on a conversation, it acts as a persistent persona: the AI will follow those instructions for every message in the conversation. Use system prompts when you want the AI to always respond in a specific role, tone, or style (for example, "You are a concise code reviewer" or "Respond only in formal French").

**User prompts** are templates for tasks you do repeatedly. You insert them into the chat input and send them as a message. Use user prompts for things like "Summarize the key points of the text I'm about to share" or "Write unit tests for the code below."

## The Library

Your prompts live in the **Library** (the Library icon in the left rail). It shows your prompts and skills as a gallery of cards.

### Browsing and searching

Use the search box at the top of the gallery to find prompts by name or description. The sidebar offers scope filters (**All**, **Favorites**, and in a workspace also **Shared** and **Personal**) plus a tag list to narrow down by topic.

Each card shows the name, a short description, and any tags. Click a card to see the full content before deciding to use it.

### Favorites

Open a prompt and click the star icon to add it to your favorites. Favorited prompts show up under the **Favorites** filter in the Library and in the **Favorites** tab of the prompt panel inside a conversation. This makes it quick to reach the prompts you use most often.

## Activating a prompt on a conversation

### Activating a system prompt

Inside a conversation, click **Tools** in the header and open the **Prompts** tab. Hover over a system prompt and click the activate button. The prompt is applied immediately and persists for all subsequent messages. The panel shows the currently active prompt at the top; click the X next to it to deactivate.

You can also write a one-off system prompt for a single conversation in the **Settings** tab of the Tools panel.

### Using a user prompt

User prompts are inserted into the chat input. Open the **+** menu in the composer and choose **Insert prompt** to pick one from your library, or use the **Prompts** tab of the Tools panel and click the insert button on a user prompt. The text lands in the input field, where you can edit it before sending.

From the Library, the **Use prompt** button on a prompt's page starts a fresh conversation with the prompt content already in the composer.

## Tags and filtering

Tags help you organize and find prompts. In the Library sidebar, click any tag to filter the gallery to prompts with that tag. You can combine a tag filter with a search query to narrow down further.

When creating or editing a prompt, you can add multiple tags to make it easier to find later.
