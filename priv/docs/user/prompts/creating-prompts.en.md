# Creating Prompts

You can create your own prompts to save instructions you use frequently. Prompts can be kept private, shared with your workspace, or published.

## Ways to create a prompt

### From the Library

Open the **Library** from the left rail and click **New** at the top of the sidebar, then choose **New prompt**. This opens the prompt dialog with a blank form.

### From a message in chat

If you've written a message that works really well as a reusable template, you can save it as a prompt directly. Hover over the message and click the **create prompt** action (the sparkles icon). The message text will be pre-filled in the prompt dialog so you can review and adjust it before saving.

## Filling in the prompt details

### Name and description

Give your prompt a clear, memorable name. The description appears on the prompt card in the Library, so write a sentence or two explaining what the prompt does and when to use it.

### Prompt type

Choose one of two types:

- **System prompt:** The content will be used as a persona or behavioral instruction for the AI. It's applied to a conversation as a whole and shapes how the AI responds to every message.
- **User prompt:** The content is a message template inserted into the chat input. It's useful for tasks you do repeatedly, like formatting requests or analysis patterns.

### Content

Write the actual prompt text. For system prompts, this is where you define the AI's role, tone, constraints, and any specific behaviors. For user prompts, write the template message you want to reuse. You can leave placeholder text where you'll fill in specific details before sending.

### Tags

Add tags to make the prompt easier to find in the Library. Use tags that describe the topic, style, or use case (for example: writing, coding, research, formal, concise). You can add multiple tags; press **Enter** after each one. Inside a workspace, tags are shared with the team.

## Sharing and publishing

By default, new prompts are private and only visible to you. On a prompt's page, the menu in the top right offers:

- **Share to workspace**: makes the prompt available to everyone in your current workspace (only shown while you're in a workspace).
- **Publish to library**: marks the prompt as public. A **Public** badge appears on the prompt; **Unpublish from library** reverses it.

You can change these at any time from the prompt's page. Editing is always available via the **Edit** button there.
